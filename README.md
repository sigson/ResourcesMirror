# ResourcesMirror — ветка godot4

Зеркало `res://Resources` для клиентов на Godot 4.7 (DotTanks4). Чанки — pck формата
GDPC v3 (Godot 3 их не читает; зеркало Godot 3 живёт в ветке `main`).

Клиент берёт `https://raw.githubusercontent.com/sigson/ResourcesMirror/godot4/`.
Генератор: `DotTanks4/tools/resource-mirror/mirror_gen.py` (см. README рядом с ним).
